
                         LESSON LINK — СИСТЕМА УПРАВЛЕНИЯ
                    образовательной организацией (учебный центр)

ОПИСАНИЕ ПРОЕКТА
----------------

Lesson Link — настольное приложение для автоматизации работы учебного центра
или другой образовательной организации. Система поддерживает работу нескольких
организаций (мультитенантность): данные каждой организации изолированы.

Приложение предназначено для двух ролей пользователей:
  • Администратор организации — полное управление структурой и данными;
  • Преподаватель — работа с группами, учениками, расписанием, посещаемостью
    и оценками.

Интерфейс выполнен на WPF с адаптивной вёрсткой: окна масштабируются,
элементы прокручиваются, таблицы подстраиваются под содержимое.


ТЕХНОЛОГИИ
----------

  • Язык программирования: C#
  • Платформа: .NET Framework 4.8
  • Интерфейс: WPF (Windows Presentation Foundation)
  • СУБД: Microsoft SQL Server
  • Доступ к данным: Microsoft.Data.SqlClient
  • Тестирование: xUnit (проект Lesson Link.Tests)


СИСТЕМНЫЕ ТРЕБОВАНИЯ
--------------------

  • ОС: Windows 10 / 11
  • .NET Framework 4.8
  • Microsoft SQL Server (в проекте используется экземпляр SQLEXPRESS01)
  • Visual Studio 2022 (рекомендуется) для сборки и отладки


СТРУКТУРА РЕШЕНИЯ
-----------------

  Lesson Link.sln              — файл решения Visual Studio

ОСНОВНОЙ ФУНКЦИОНАЛ
-------------------

Для администратора:
  • Регистрация организации и учётной записи администратора
  • Управление профилем организации
  • Направления обучения
  • Сотрудники (преподаватели)
  • Группы (вместимость, цена, аудитория, описание)
  • Зачисление и отчисление учеников в группы
  • Назначение преподавателей в группы
  • Расписание занятий
  • Карточки учеников (ФИО, пол, возрастная группа, родители, мед. показания)
  • Методические материалы
  • Просмотр успеваемости и посещаемости учеников

Для преподавателя:
  • Личные данные и профиль
  • Мои группы
  • Моё расписание
  • Список учеников
  • Отметка посещаемости на занятиях
  • Выставление оценок
  • Методические материалы

Общие возможности:
  • Авторизация по email и паролю
  • Валидация регистрации (email по RFC 5322, сложность пароля)
  • Поиск учеников по имени и фамилии (ручной ввод в поле)
  • Блокировка входа преподавателя при неактивной организации
  • Сохранение паролей в виде SHA-256 хеша


УСТАНОВКА И ЗАПУСК
------------------

1. Подготовка базы данных
   • Создайте базу данных с именем Lesson в SQL Server.
   • Выполните основной скрипт создания таблиц (если он предоставлен отдельно).
   • Выполните скрипт SchemaExtensions.sql в базе Lesson — он добавляет
     поля ученика, таблицы посещаемости (LessonAttendance) и оценок
     (StudentGrade), а также другие расширения схемы.

2. Настройка подключения
   • Откройте файл Helpers\DatabaseHelper.cs.
   • При необходимости измените строку подключения ConnectionString:
     Server=localhost\SQLEXPRESS01;Database=Lesson;Integrated Security=True;Encrypt=False;

3. Сборка проекта
   • Откройте Lesson Link.sln в Visual Studio 2022.
   • Выполните восстановление пакетов NuGet (ПКМ по решению → Restore NuGet Packages).
   • Соберите конфигурацию Debug или Release (Ctrl+Shift+B).

4. Запуск
   • Запустите проект Lesson Link (F5) или выполните файл:
     bin\Debug\Lesson Link.exe

5. Первый вход
   • На главном окне нажмите ссылку регистрации и создайте организацию
     и учётную запись администратора.
   • Либо используйте существующие учётные данные, если они уже есть в БД.


ЮНИТ-ТЕСТЫ
----------

Проект Lesson Link.Tests содержит автоматические тесты для:
  • валидации регистрации (RegistrationValidation);
  • правил входа в систему (LoginAccessPolicy);
  • поиска учеников (StudentSearchHelper);
  • хеширования паролей (DatabaseHelper);
  • моделей Student и AppSession.

Запуск через Visual Studio:
  Test → Test Explorer → Run All Tests

Запуск из командной строки (после сборки):
  vstest.console.exe "Lesson Link.Tests\bin\Debug\net48\Lesson Link.Tests.dll"
